# LifePilot AI

## AI-Powered Life & Career Assistant

LifePilot AI is a full-stack web application designed to help students manage their goals, study plans, daily tasks, and career development with the support of Artificial Intelligence.

The application combines productivity tools and AI-powered assistance into a single platform.

## Live Demo

🌐 Live Website: https://lifepilot-tycf.onrender.com

## Features

### AI Assistant

LifePilot AI provides an intelligent chat assistant powered by Google Gemini.

Users can ask questions related to:

- Programming
- Software Development
- Artificial Intelligence
- Machine Learning
- Data Analytics
- Career Development
- Study Planning
- Productivity
- Learning Strategies

The assistant provides practical and personalized guidance.

### Personalized AI

The AI assistant can use information from the user's LifePilot data to provide more relevant responses.

It can consider:

- Goals
- Study Plans
- Tasks
- Task Priorities
- Completed Tasks

### Goal Management

Users can:

- Create goals
- View goals
- Delete goals

Examples:

- Learn Python
- Become a Software Developer
- Learn AI/ML
- Prepare for Placements
- Build Projects

### Study Planner

Users can organize their learning activities by:

- Adding subjects
- Setting study hours
- Viewing study plans
- Deleting study plans

### Task Management

Users can:

- Create tasks
- Set task priority
- Mark tasks as completed
- Mark tasks as incomplete
- Delete tasks

### Dashboard

The dashboard provides a quick overview of the user's activity.

It includes:

- Total Goals
- Study Plans
- Tasks
- Completed Tasks
- Progress Information
- AI Daily Suggestions

### Career Guidance

LifePilot provides career-related guidance for students interested in areas such as:

- Software Development
- Python Development
- Full-Stack Development
- Artificial Intelligence
- Machine Learning
- Data Analytics
- Interview Preparation
- Skill Development

### User Authentication

The application includes:

- User Registration
- User Login
- User Logout
- Profile Management
- Password Change
- User-specific Data

### Multiple AI Conversations

Users can:

- Create new conversations
- Continue existing conversations
- Delete individual conversations
- Clear conversations
- Maintain separate conversations for different topics

### Responsive Design

LifePilot is designed to work on:

- Desktop
- Laptop
- Tablet
- Mobile
